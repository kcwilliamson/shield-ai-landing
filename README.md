# Shield AI Landing Page

A modern, animated landing-page prototype built with Astro, React, and GSAP. The project explores how to explain content-protection choices, AI training-data concerns, and product tradeoffs through an educational marketing experience.

## Features

- Multi-section landing page
- Scroll-triggered animation and parallax effects
- Interactive protection-level slider
- Video carousel
- Expandable resource section
- Responsive design

## Product Thinking

This prototype focuses on:
- helping users understand a complex topic quickly
- turning abstract policy choices into visible tradeoffs
- pairing educational content with decision support
- balancing narrative, interaction, and conversion

## Tech Stack

- Astro
- React
- TypeScript
- GSAP
- Tailwind CSS

## Content Structure

1. **Hero** - frames the tension between access and protection
2. **Education** - explains how content may be used by AI systems
3. **Perspectives** - surfaces supporting material and expert context
4. **Protection Levels** - compares multiple strategic choices
5. **Resources** - offers deeper reading for users who need more detail

## Development

```bash
npm install

npm run build
```
